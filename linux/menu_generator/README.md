# menu_generator

交互式 Bash 菜单脚本生成器 —— 帮你快速搭建带菜单循环的脚本框架。

## 功能

- 交互式输入菜单标题与选项（回车结束输入）
- 自定义函数名前缀（默认 `option`）
- 自动生成带菜单循环的 `generated_menu.sh`，并赋予执行权限
- 每个选项自动生成一个函数空壳（`option1()`、`option2()`…），标注 TODO

## 用法

```bash
bash menu_generator.sh
```

按提示依次输入：

1. 菜单标题（如「系统管理工具」）
2. 菜单选项（每行一个，直接回车结束）
3. 函数名前缀（默认 `option`）

生成 `generated_menu.sh` 后，编辑其中的函数体即可：

```bash
option1() {
    echo "执行: 选项一"
    # TODO: 在这里写功能代码
}
```

## 注意事项

- 生成的函数都是空壳，功能代码需要自己填写
- 菜单选项 0 固定为退出
- 生成文件为当前目录下的 `generated_menu.sh`，若已存在会被覆盖
